# 🔐 Week 2 — Reconnaissance and Scanning

This repository documents my hands-on cybersecurity activities completed during **Networkwalks Cybersecurity Internship — Batch B084I, Week 2**.

The exercises focus on developing practical skills in information gathering, reconnaissance, and network scanning using Kali Linux tools.

### 🛠️ Practical Activities
- **theHarvester:** Gathering publicly available information, including email addresses and hostnames.
- **Kali Linux Footprinting:** Identifying domain information, web technologies, DNS records, and security technologies.
- **Zenmap Local Network Scanning:** Exploring network hosts and services through graphical Nmap scanning.

### 🎯 Learning Objectives
- Understand reconnaissance and information gathering.
- Identify publicly available information about target domains.
- Discover hosts, services, and network details.
- Gain practical experience with cybersecurity tools.
- Document findings and improve technical reporting skills.

**Note:** All activities are intended for educational purposes and must only be conducted against authorized targets.

**🔐 Learn responsibly. Test ethically. Document professionally.**
